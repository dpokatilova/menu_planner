## Опис

MenuPlanner — вебплатформа для пошуку рецептів і планування меню на тиждень.
Призначена для всіх, хто хоче швидко знайти страву за назвою, категорією чи
продуктом і скласти собі план харчування з автоматичним списком покупок.

## Ролі

- **Гість:** переглядає каталог рецептів, шукає, фільтрує за категоріями та обмеженнями, сортує за часом приготування і калорійністю.
- **Користувач:** усе, що гість, а також складає меню на тиждень, переглядає історію планів харчування в профілі, отримує список покупок, користується AI-підбором рецептів і пропонує власні рецепти.
- **Модератор:** перевіряє рецепти, запропоновані користувачами та імпортовані з публічного API: схвалює, відхиляє з коментарем або доповнює. Веде довідники продуктів, категорій і тегів.
- **Адміністратор:** усе, що модератор, а також керує користувачами та їхніми ролями.

Модерація і керування ролями виконуються через Django-адмінку, окремих API-ендпоінтів для них немає.

## Основний функціонал

- Каталог рецептів із пошуком за назвою страви.
- Фільтри за категоріями (сніданок, італійська кухня тощо) та обмеженнями в харчуванні (без глютену, без лактози, вегетаріанське).
- Сортування за часом приготування та калорійністю, пагінація.
- Окремі сторінки зі стравами певної категорії або з конкретним продуктом.
- Тижневе меню: зареєстровані користувачі додають рецепти в меню, а після збереження воно стає планом харчування в історії профілю.
- Список покупок із тижневого меню: інгредієнти підсумовуються по продуктах.
- Користувачі пропонують власні рецепти, які проходять модерацію.
- Реєстрація та вхід через JWT, розмежування прав доступу за ролями.

## Особливість проєкту

- **AI-підбір рецептів** за обмеженнями в харчуванні: користувач описує свої обмеження звичайними словами, AI обирає страви лише з каталогу MenuPlanner і пояснює вибір.
- **Наповнення бази через імпорт:** рецепти тягнуться з публічного API, AI перекладає їх, проставляє теги й калорії та нормалізує інгредієнти, після чого рецепт потрапляє на перевірку модератору.
- **Підказки щодо залишків продуктів:** якщо рецепт потребує 100 г сметани, а в магазині банка 250 г, система пропонує рецепти на наступні дні, які використають залишок.
- **Автоматичний список покупок** із тижневого меню.

## API

Документація: `/api/docs/`, схема: `/api/schema/`.

| Метод | Шлях | Опис |
|---|---|---|
| POST | `/api/auth/register/` | реєстрація |
| POST | `/api/auth/login/` | вхід, повертає `access` і `refresh` |
| POST | `/api/auth/refresh/` | новий `access`, старий `refresh` гаситься |
| POST | `/api/auth/logout/` | `refresh` у чорний список |
| GET | `/api/auth/me/` | дані користувача та його роль |
| POST | `/api/menus/` | створити меню-чернетку на тиждень (`week_start` — понеділок) |
| GET | `/api/menus/` | мої меню; `?status=saved` — історія |
| GET, DELETE | `/api/menus/{id}/` | перегляд і видалення меню |
| POST | `/api/menus/{id}/items/` | додати рецепт (`recipe`, `date`, `meal_type`) |
| DELETE | `/api/menus/{id}/items/{item_id}/` | прибрати рецепт |
| POST | `/api/menus/{id}/save/` | зберегти меню в історію |

## Запуск проєкта

### Вимоги

- Python 3.12

### Встановлення

```bash
git clone <https://github.com/dpokatilova/menu_planner.git>
cd menu_planner
```

Віртуальне середовище:

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell)**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Налаштування

Скопіюйте `.env.example` у `.env` і заповніть значення:

- macOS / Linux: `cp .env.example .env`
- Windows: `copy .env.example .env`

| Змінна | Опис |
|---|---|
| `SECRET_KEY` | Секретний ключ Django |
| `DEBUG` | `True` для розробки, `False` для продакшену |
| `ALLOWED_HOSTS` | Домени через кому, наприклад `localhost,127.0.0.1` |
| `CORS_ALLOWED_ORIGINS` | Адреса фронтенду, наприклад `http://localhost:5173` |
